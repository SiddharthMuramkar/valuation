# Glossary

**Valuation** — An intrinsic-value estimate for one Company, built with Damodaran's FCFF simple Ginzu method from a set of Story Inputs. Produces value per share.

**Story Inputs** — The narrative-driven assumptions of a Valuation: revenue growth, target operating margin, sales-to-capital, cost of capital, and similar.

**Verdict** — Buy / Hold / Sell judgement from comparing a Valuation's value per share to market price against configurable margin-of-safety bands, with a rationale citing Corpus sources.

**Corpus** — Everything Aswath Damodaran has published openly (blog posts, notes, papers, spreadsheets, datasets) as stored for retrieval.

**Damodaran Dataset** — One of his periodically published data tables (ERP, country risk, industry betas, margins, etc.).

**Watchlist** — The set of Companies the user tracks. There is no portfolio concept.
